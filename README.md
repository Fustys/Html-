# Разработка пользовательского Web-интерфейса

Лабораторные работы по курсу. Каждая работа лежит в своей папке и опубликована через GitHub Pages — страницы открываются прямо в браузере по ссылкам ниже.

## Работы

| № | Открыть сайт | Тема | Что применено |
|---|---|---|---|
| 1 | [Гиперссылки и форма](https://fustys.github.io/ИМЯ-РЕПОЗИТОРИЯ/laba1/) | Ссылки всех типов, HTML-форма | абсолютные и относительные URL, якоря, карта ссылок, `rel="nofollow"`, поля формы |
| 2 | [Шапка, таблица, подвал](https://fustys.github.io/ИМЯ-РЕПОЗИТОРИЯ/laba2/) | Блочная вёрстка | `float`, clearfix, `max-width: 960px` с центровкой, объединение ячеек, чередование строк, контроль ввода в форме |
| 3 | [Адаптивная вёрстка](https://fustys.github.io/ИМЯ-РЕПОЗИТОРИЯ/laba3/) | Mobile First | Flexbox, Media Query, `order` для перестановки блоков без изменения HTML |

## Лабораторная 1 — гиперссылки и форма

Список из 21 ссылки: по http и https, относительные разных уровней вложенности, якорь на фрагмент страницы, URL с параметрами, карта ссылок на изображении (`<map>` и `<area>`), FTP, ссылка с запретом на индексацию. Плюс форма-анкета с текстовыми полями, переключателями, списком множественного выбора и флажком.

## Лабораторная 2 — шапка, меню, таблица, подвал

Страница из первой работы, дополненная шапкой с логотипом и названием, меню, таблицей и подвалом. Шапка и подвал тянутся на всю ширину окна, контент ограничен 960px и выровнен по центру. Всё оформление вынесено в отдельный `style.css`, стили подключаются через id и классы, ни одного атрибута `style` в разметке.

Таблица содержит строку-заголовок, четыре колонки, шесть строк и три вида объединения ячеек — `colspan="4"`, `rowspan="2"` и `colspan="2"`. Фон чётных и нечётных строк различается через `:nth-child`.

Форма дополнена проверкой ввода средствами HTML5: `required`, `pattern`, `min` и `max` для даты, ограничения длины. Подсветка ошибок сделана через `:user-invalid`, чтобы поля не краснели до того, как пользователь начал заполнять форму.

## Лабораторная 3 — адаптивная вёрстка Mobile First

Та же страница, переверстанная под мобильные устройства.

Все базовые правила в `style.css` написаны для смартфона, а расширения для больших экранов подключаются одним медиазапросом `min-width: 768px` в конце файла — это и есть принцип Mobile First. Меню на телефоне выводится вертикальным списком, шапка, навигация, контент и подвал занимают всю ширину экрана.

В HTML список гиперссылок стоит раньше таблицы, но на смартфоне таблица показывается выше — за счёт свойства `order` внутри флекс-контейнера. Порядок элементов в разметке при этом не меняется.

## Как это опубликовано

GitHub Pages включается в настройках репозитория: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main / (root) → Save**. Через минуту страницы становятся доступны по адресу `https://fustys.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.
